**Type codes:** TYP = typical at 25 °C; MIN/MAX = guaranteed at 25 °C; CURVE = read from a typical-characteristic plot; DERIVED = calculated here. Vector-sampled curves (Figs. 18, 21, 24) are read from the PDF path coordinates.

## Identity and stability
- Voltage feedback, bipolar (XFCB3/SiGe), rail-to-rail output, 3 mA per amplifier. **Decompensated: stable for G ≥ 10** (title p1; p19).
- **Below G = 10** (p19, Fig. 50, Table 11): an R1–C1 network from −IN to ground holds the HF noise gain near +9/+10 while the LF gain is +5 to +9. G = +5: R1 = 49.9 Ω, C1 = 60 pF, RF = 200 Ω, RG = 49.9 Ω, RO = 49.9 Ω, CL = 150 pF (resonance 53 MHz, HF noise gain ≈ +9, peaking "a little over 2 dB"); Table 11 also covers +6, +7, +8, +9.
- **TIA guidance (p21):** the capacitive noise gain (C_S + C_M + C_F + C_D)/C_F must be kept **greater than 10**.

## TIA content (p21: "Wideband Photomultiplier Preamplifier", Figs. 55–56, Table 12) — analytical only
- V_OUT = I_PHOTO · R_F / (1 + s C_F R_F).
- 45° phase-margin bandwidth f(45) = √(GBP / (2π R_F C_S)); C_F = √(C_S / (2π R_F GBP)); C_S = total summing-junction capacitance (amplifier + photomultiplier + board). Gives ≈2 dB peaking and 15% overshoot; doubling C_F and halving the bandwidth gives a flat response with ≈5% overshoot.
- Noise corners f1 = 1/(2π R_F (C_S + C_M + C_F + C_D)), f2 = 1/(2π R_F C_F), f3 = GBP / ((C_S + C_M + C_F + C_D)/C_F); rms contributions √(4kT R_F f2 · 1.57), e_n (C_S + C_M + C_F + C_D)/C_F · √(f3 · 1.57), i_n R_F √(f2 · 1.57).
- Capacitive noise gain must stay above 10; the input bias current (−11 µA) and current noise matter with large R_F. No numerical example (no R_F, C_F, C_S or bandwidth values).
