# AD8099 (Analog Devices) — spec sheet extract

**Source:** `datasheets/ad8099_distributor_copy.pdf` — AD8099 Data Sheet, **Rev. E** (7/2016), document code **D04511-0-7/16(E)** (printed on p26). Distributor-hosted copy of the manufacturer PDF; status "Data Sheet" (production). PDF page index = printed page number ("Page N of 26").

**Type codes:** TYP = typical at 25 °C; MIN/MAX = guaranteed at 25 °C (no over-temperature limits); CURVE = read from a typical-characteristic plot (uncertainty stated); DERIVED = calculated here from datasheet numbers.

## Identity and compensation
- Voltage-feedback, bipolar (XFCB) input, single gain stage plus unity-gain buffer, **external compensation pin CC** (Fig. 58, p15).
- **Minimum stable gain:** noise gain 2 (G = +2 or −1) *with* the external RC/CC/C1 network and CF of Table 4. "Can be externally compensated down to a gain of 2 … Above gains of 15, no external compensation network is required" (p15); "In low gain configurations (less than 15) the AD8099 requires external compensation" (p16); Features: "gain range −1, +2 to +10". "Not unity-gain stable" (p22); a net +1 is built from +2 and −1 stages.
- **No guidance below noise gain 2, none for capacitive (TIA) feedback or noise-gain shaping, and no TIA example.** The only related text: CF "creates a zero in the loop response to compensate the pole created by the input capacitance (including stray capacitance) and the feedback resistor"; typical 0.5–1.5 pF (p16).

- **Open-loop curves and noise for each compensation setting are NOT given**; only the uncompensated open-loop response exists (below). Phase margin of the compensated configurations is not stated (only peaking).

Highest plotted ≈400 MHz. Above ≈100 MHz the trace bumps to ≈1.33 nV/√Hz near 230 MHz and then falls far below the white level — a measurement roll-off, so values above ≈150 MHz are not usable. 1/f corner ≈5 kHz (DERIVED; 3–9 kHz depending on fit; the low-f slope is ≈f^−0.38).

- Layout (p23): the CC-pin area is very sensitive to parasitic capacitance — no trace near the CC pin when uncompensated; when compensated make the CC/−Vs/RC/C1/CC traces wide; clear planes under the pins (one SOIC pad can add 0.2 pF); 0508-size bypass caps between supplies; NP0 for CF (X7R drift causes peaking); solder the paddle to ground. LFCSP gives better HD2 into heavy loads and better capacitive-load drive with primary-output feedback (p15).
- DISABLE (Table 5, p21): −5 to +2.4 V disables (±5 V), open enables, 4.3–5 V low-bias mode; turn-off 105 ns, turn-on 39 ns; off isolation −61 dB at 1 MHz.

## Absolute maximum and input protection
Supply 12.6 V; differential input ±1.8 V; differential input current ±10 mA; storage −65 to +125 °C; operating −40 to +125 °C; junction 150 °C (Table 3, p5). Antiparallel diode pairs clamp the differential input to ≈±1.8 V; ESD diodes to both rails; text says diodes handle 5 mA steady state (p15).

## Uncertain or contradictory items
1. Differential input current: Table 3 ±10 mA vs text (p15) 5 mA steady-state limit.
2. Slew rate at G = +2: 475 (Features) vs 470 (Table 1) vs 515 SOIC / 475 LFCSP (Table 4).
3. GBWP 3.8 GHz (no conditions) vs closed-loop G·BW 3.2 GHz (G = +20) and 5.5 GHz (G = +10 with peaking).
4. Table 2 (+5 V) repeats operating range "±5 / ±6 V"; Table 2 swing MIN = TYP for 1 kΩ and the 100 Ω TYP equals the 1 kΩ TYP.
5. Bias cancellation: "factor of 60" (p21), "< 200 nA" (p15) vs Table 1 −0.1 µA typ / −2 µA max.
6. Input capacitance 2 pF vs ≈5.6–5.9 pF effective from Fig. 18 (fixture included).
7. Typical-characteristics header cites Figs. 63–66, Table 1 cites Figs. 60–66; Table 4 has no units.
8. Noise curves above ≈100–150 MHz show measurement roll-off; the current-noise bump at 70–80 MHz may or may not be real.
9. Only the uncompensated open-loop curve exists; no phase margin for compensated settings.
